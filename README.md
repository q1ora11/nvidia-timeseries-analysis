# Анализ временных рядов: NVIDIA Daily Stock Prices

Раздел: Анализ временных рядов  
Задача: **Прогнозирование стоимости акций**

## Датасет

[NVIDIA Daily Stock Prices 2016–2026](https://www.kaggle.com/datasets/ibrahimshahrukh/nvidia-daily-stock-prices-20162026-dataset/data) — 2514 торговых дней, 5 каналов: Close, High, Low, Open, Volume.


## Этапы анализа

| # | Этап | Ключевой результат |
|---|------|--------------------|
| 1 | Загрузка данных | 2514 строк, 5 каналов, пропусков нет |
| 2 | Визуализация | Сильный восходящий тренд, разбивка 80/20 |
| 3 | Статистический анализ | Правая асимметрия, Volume в другом масштабе |
| 4 | Пропуски и выбросы | 0% пропусков, 0.56–1.35% выбросов |
| 5 | Диапазоны значений | Нормализация обязательна |
| 6 | Корреляционный анализ | Close/High/Low/Open: r > 0.999 |
| 7 | Анализ шума | SNR = 33.28 дБ — данные очень чистые |
